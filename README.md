# ALT Study — Русский язык B1

Веб-сайт для просмотра силлабуса по русскому языку B1 (2 курс, 4 семестр, 2026–2027 учебный год).

## Как открыть

1. Распакуйте ZIP.
2. Откройте папку `russian-syllabus-site` в VS Code.
3. Откройте `index.html` через расширение Live Server (Open with Live Server), либо двойным щелчком в браузере.
4. Интернет нужен только для загрузки шрифта Manrope; без интернета сайт тоже работает со стандартным шрифтом.

## Страницы

- Обзор курса — сведения и модули
- Учебный план — 15 недель, поиск и фильтр модулей
- Задания — ПЗ, СРО, СРОП; отмеченные задания запоминаются в LocalStorage
- Оценивание — веса контроля и шкала буквенных оценок
- Документ PDF — оригинальный PDF силлабуса внутри сайта

## Файлы

- `index.html` — структура сайта
- `style.css` — оформление и мобильная адаптация
- `data.js` — данные по неделям и оцениванию
- `script.js` — переключение страниц, поиск, фильтры, отметки
- `syllabus.pdf` — предоставленный оригинал документа

## Источник и особенности

Силлабус ALT Университета, «Русский язык (уровень B1)», 2026–2027.
Темы недель и задания сведены по разделам 5.6, 5.8, 5.9, 5.10; оценивание — по 5.7, шкала — по 5.12.
Сроки самостоятельных работ показаны как день недели и время, **без выдумывания календарных дат**.
В исходном PDF встречаются расхождения между расписанием недель и графиком дедлайнов: интерфейс использует для СРО/СРОП таблицы 5.8 и 5.9. Отдельные формулировки сокращены для удобства чтения; точные формулировки см. в PDF.
Это демонстрационный локальный учебный проект, не официальный портал университета.
